# API de projets collaboratifs

Structure initiale du projet (Express + JWT + upload PDF + stockage mémoire).

## Démarrage

1. Copier `.env.example` vers `.env`
2. Installer les dépendances : `npm install`
3. Lancer en dev : `npm run dev`

## Arborescence

- `src/` : code source
- `uploads/` : stockage des PDF
- `tests/` : tests API
